# Workflow details

## Input backbone

`examples/input/c05_cyclic_backbone.pdb` is a historical C05-derived cyclic-peptide backbone retained only as a geometry example. It is not generated by the new workflow.

For a new design, replace it with a backbone from your preferred modern backbone-generation method. The important requirements are:

- one protein chain containing the cyclic peptide;
- standard amino-acid residues where possible;
- physically plausible head-to-tail geometry;
- no reliance on Rosetta-specific residue numbering or params files.

## ProteinMPNN stage

The wrapper intentionally calls the official ProteinMPNN program rather than copying its source into this repository. The official script accepts a single PDB via `--pdb_path`, can select the designed chain with `--pdb_path_chains`, and writes sampled sequences under the requested output directory. citeturn960788search0

A cyclic backbone is treated as a geometric target. ProteinMPNN itself is a sequence-design model, so the old Rosetta `resfile`, constraints, and XML machinery are not required in this example.

## ESMFold2 stage

ESMFold2 currently exposes a local inference API through `ESMFold2Model` and `ESMFold2InputBuilder`. The input data model includes `CovalentBond`, which lets this example encode the head-to-tail bond explicitly. citeturn457844search0turn206872search4

The example uses:

```text
A:residue 0 atom N  --  A:last_residue atom C
```

This is the peptide backbone cyclization bond. The code uses the standard-residue atom ordering where N is index 0 and C is index 2. citeturn171300search0

## Interpretation

Use mean pLDDT and closure distance for triage, not as a substitute for experimental validation. ESMFold2 can predict all-atom structures and exposes confidence metrics; it does not establish permeability, solubility, target binding, protease resistance, or pharmacological activity. citeturn457844search0

For a real campaign, add independent filters such as steric clashes, backbone torsion sanity checks, sequence liability filters, and target-specific structural assessment.
